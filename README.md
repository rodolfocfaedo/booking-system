# Booking System

Backend API for managing reservations of resources such as meeting rooms, barbershops, studios, and other reservable assets.

## Project Purpose

This project is being developed as a backend portfolio application to demonstrate best practices in Java and Spring Boot development.

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Gradle
- OpenAPI / Swagger

## Current Status

Planning and documentation phase.

## Documentation

Detailed project documentation is available in the `/docs` folder.

## Planned Evolution

- CRUD for resources and bookings
- Business rule validation
- Spring Security + JWT
- Tests
- Docker
- CI/CD
- Microservices
